# Strong Peggles

App (PWA) de treino em máquinas, dieta, água, pesagem e fotos semanais. Os dados ficam só no celular (IndexedDB); este repositório guarda apenas o código.

Lembretes: agendados pelo próprio app no ntfy.sh (até 3 dias à frente).

Ilustrações de exercícios (pasta ilu/): Everkinetic (http://everkinetic.com), licença CC BY-SA 4.0, adaptadas (início e fim lado a lado).
